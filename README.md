## Selected work

<details open>
<summary><b>Handover</b> | project memory for research labs | Next.js, TypeScript, Supabase</summary>
<br/>

Research labs lose what students know when they graduate. A model turns weekly check-ins and interview transcripts into a project memory, code verifies every quote it cites, and a professor approves before anything is shared. I built it alone for the Meta Global AI Developer Hackathon.

[Code](https://github.com/Siddharthprabhakar/Handover) | [Live demo](https://handover-dusky.vercel.app/)
</details>

<details>
<summary><b>AccessDraft</b> | accessible accommodation requests | React, Vite, Figma</summary>
<br/>

A mobile-first app that helps people draft accommodation requests and works with a screen reader. Team of six. Tested on iPhone VoiceOver with a blind accessibility professional.

[Code](https://github.com/Siddharthprabhakar/AccessDraft) | [Live](https://siddharthprabhakar.github.io/AccessDraft/)
</details>
